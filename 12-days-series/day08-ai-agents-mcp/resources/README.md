## Libraries & Frameworks

### Agent Frameworks
- **LangChain** - Most popular agent framework with extensive tool support
- **LlamaIndex** - Specialized for RAG and data-connected agents
- **AutoGen** (Microsoft) - Multi-agent conversation framework
- **CrewAI** - Role-based agent collaboration
- **Haystack** - Search and QA pipeline framework

### Tool Libraries
- **langchain-tools** - Pre-built tools for LangChain
- **llama-index-tools** - Tools for LlamaIndex
- **mcp-sdk** - Official MCP implementation

## Datasets & Benchmarks

- **AgentBench** - Benchmark for evaluating agent capabilities
